# File metadata

This file details the specific contents of each file generated by BridGE and is separated by module.

## DataProcess (data_tools.py)

### convert_plink()

This function takes in PLINK2 files and extracts the necessary information to run BridGE. This information is saved as a numpy archive file named 'snp_data.npz'. It contains the following arrays.

- data: a 2D genotype array where rows are samples, columns are variants, and values are how many alternative alleles are present (0, 1, 2). Any missing data is replaced with zeros.
- varid: the name of the SNP/variant IDs. Typically are rsIDs for SNP chips, but denoted as 'varid' as BridGE 3.0 can handle WES data.
- chrom: chromosome identifier per variant.
- pos: position number per variant.
- pheno: phenotype per sample.
- iid: sample identifier.
- sex: sex per sample.

### gene2pathway()

This function takes in MSigDB gene set files, filters for pathway size and similarity, and saves the resulting gene to pathway mapping as a parquet data frame named 'gene_pathway_mapping.parquet'. Rows are genes, columns are pathways, and values are bools indicating if a gene is mapped to a pathway.

Additionally, the resulting filtered gene sets are saved back to the 'raw' directory and are indicated with the added 'filtered' designation. For example, for files 'c2.cp.v2026.1.Hs.entrez.gmt' and 'c2.cp.v2026.1.Hs.symbols.gmt', the saved filtered files are called 'c2.cp.v2026.1.Hs.filtered.entrez.gmt' and 'c2.cp.v2026.1.Hs.filtered.symbols.gmt'

### snp2gene()

This function takes in the PLINK2 .pvar file and a gene annotation file (provided from the refdata directory and named glist-38) and saves a parquet data frame where rows are SNPs, columns are genes, and values are bools that indicate if a SNP is mapped to a gene. This gene annotation file should be in .bed format and should have the gene boundaries expanded on either side. We recommend a 50,000 base pair extension, but this can be changed using the 'convert_glist.py' file found in the 'refdata' directory.

### snp2pathway()

This function saves a SNP to pathway mapping as a parquet data frame by using the SNP to gene mapping and gene to pathway mapping created above. Rows are SNPs, columns are pathways, and values are saved as ints.

### pathway_indices()

This function uses the SNP to pathway mapping to create a list of WPMs and BPMs that will be evaluated. We previously filtered out pathways with less than 'minPath' or greater than 'maxPath' number of genes, and here we filter out pathways with less than 'minPath' number of SNPs that are mapped to each WPM and BPM. Two parquet data frames are saved, one for WPMs and one for BPMs.

- pathway_indices-wpm.parquet: Data frame with all WPM associated data
  - pathway: pathway names
  - ind: SNP indices for each pathway
  - indsize: size of ind
  - size: size of the within pathway module
- pathway_indices-bpm.parquet: Data frame that has all BPM associated data
  - path1names: pathway 1 names
  - ind1: SNP indices in pathway 1 that are not in pathway 2
  - ind1size: size of ind1
  - path2names: pathway 2 names
  - ind2: SNP indices in pathway 2 that are not in pathway 1
  - ind2size: size of ind2
  - size: size of the between pathway module

## ComputeInteraction (compute_interactions.py)

This module will run a specifc SNP interaciton model for a real or random network. SNP interaction models can be either dominant-dominant (DD), recessive-dominant (RD), recessive-recessive (RR), or combined. With combined, the maximum score of DD, RD, and RR is used for each SNP interactions where 1=RR, 2=DD, and 3=RD. SNP interactions are saved as a single file for both protective and risk SNP interactions scores. Files are named as 'snp_interaction_networks-\<SNP interaction model>-R\<network number>.npz' and contain the following sparse arrays. For a 'combined' model with 1 real network and 10 random networks (0-10), there will be 44 files saved (4 SNP interaction models, 11 networks).

- risk: sparse array of risk SNP interaction scores
- protective: sparse array of protective SNP interaction scores
- risk_max_id: integer ID of where the risk max score came from
- protective_max_id: integer ID of where the protective max score came from

## ComputeStats (compute_stats.py)

This module will identify significant pathways using the real and random risk and protective SNP interaction networks. Results are saved as a protective of risk numpy array file for each real and random network. For 1 real network and 10 random networks (0-10), there will be 22 files saved (2 network types, 11 networks). P-values depends on if the interaction network is optionally binarized. If binarized, p-values are chi2, otherwise they are ranksum. Each file contains the following arrays.

- bpm_local: p-values for BPMs
- bpm_local_pv: permuted empirical p-values for BPMs
- density_bpm: observed densities for BPMs
- density_bpm_expected: expected densities for BPMs
- dense_index: indices of dense BPMs
- wpm_local: p-values for WPMs
- wpm_local_pv: permuted empirical p-values for WPMs
- density_wpm: observed densities for WPMs
- density_wpm_expected: expected densities for WPMs
- path_degree: p-values for PATHs
- path_degree_pv: permuted empirical p-values for PATHs

## ComputeFDR

This module calculates the false discovery rate (FDR) for BPMs, WPMs, and PATHs, using the real and random networks for both protective and risk networks. For FDR, there are two different cases calculated: case 1 based on empirical p-values (real / # random) and case 2 based on both empirical p-values and ranksum scores. One file is saved that will be named 'result-\<SNP interaction model>-R0.npz' and contains the following arrays.

- bpm_pv: permuted empirical p-values for BPMs
- wpm_pv: permuted empirical p-values for WPMs
- path_pv: permuted empirical p-values for PATHs
- bpm_ranksum: p-values for BPMs
- wpm_ranksum: p-values for WPMs
- path_ranksum: p-values for PATHs
- fdrbpm1: case 1 FDR for BPM
- fdrbpm2: case 2 FDR for BPM
- fdrwpm1: case 1 FDR for WPM
- fdrwpm2: case 2 FDR for WPM
- fdrpath1: case 1 FDR for PATH
- fdrpath2: case 2 FDR for PATH

## Summarize

This module summarizes the results from the FDR module and saves up to 4 files. If there are significant WPMs or BPMs, an interaction list will be saved for each. Additionally, a network map will be saved as a pdf depicting the relationship between significant WPMs and BPMs and their protective or risk status. Lastly, an overall result file will be saved that contains the significant WPMs, BPMs, and PATHs.

- output-combined-R0.xlsx: The overall result file.
- interaction_list-wpm-combined-0.25.xlsx: A list of SNP interactions for significant WPMs
- interaction_list-bpm-combined-0.25.xlsx: A list of SNP interactions for significant BPMs
- network_map-combined-R0.pdf: a pdf of the network map for significant WPMs and BPMs
